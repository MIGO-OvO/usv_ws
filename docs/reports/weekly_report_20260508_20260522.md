### 2.3 本周期新增/稳定的 MAVLink 字段

| 字段 | 含义 | 生成端 | 固件动作 | QGC 消费 |
|---|---|---|---|---|
| `USV_BSET` | baseline 是否已设置 | ROS bridge | 缓存并转发 | baseline 状态、采样按钮门控 |
| `USV_REF` | baseline 参考电压 | ROS bridge | 缓存并转发 | 载荷面板显示 |
| `USV_BASE` | baseline 电压偏置 | ROS bridge | 缓存并转发 | 载荷面板/数据页显示 |
| `USV_VLD` | 分光样本有效标志 | ROS bridge | 缓存并转发 | QGC 控制按钮是否允许采样 |

这四个字段补齐了前一阶段只有电压/吸光度而缺少“样本可信度与基准状态”的问题，使 QGC 不再仅靠数值是否变化判断可操作性。

## 8. 跨端一致性与集成影响

### 8.1 命令编号一致性

| 命令 | QGC | ROS router/trigger | 泵控动作 |
|---:|---|---|---|
| 31010 | 开始点采样 | `CMD_START_SAMPLING` | `/usv/automation_start` 或手动采样流程 |
| 31011 | 停止采样 | `CMD_STOP_SAMPLING` | `/usv/automation_stop` |
| 31012 | 暂停采样 | `CMD_PAUSE_SAMPLING` | `/usv/automation_pause` |
| 31013 | 恢复采样 | `CMD_RESUME_SAMPLING` | `/usv/automation_resume` |
| 31014 | 校准 | `CMD_CALIBRATE` | 校准流程 |
| 31015 | 开始走航 | `CMD_START_SURVEY` | survey mode |
| 31016 | 停止走航 | `CMD_STOP_SURVEY` | survey stop |
| 31017 | 设置 baseline | `CMD_SET_BASELINE` | `spectrometer_baseline`，取最新有效电压或 param1 |
| 31018 | 分光启动 | `CMD_SPECTROMETER_START` | `spectrometer_start` |
| 31019 | 分光停止 | `CMD_SPECTROMETER_STOP` | `spectrometer_stop` |

命令编号在 QGC、ROS router、ROS trigger 中一致；固件本周期不新增 COMMAND_LONG 处理逻辑，只作为下行/上行路由链路的一部分。

### 8.2 载荷字段一致性

本周期后 QGC/ROS/固件对 17 个字段一致：

`USV_VOLT`、`USV_ABS`、`PUMP_X`、`PUMP_Y`、`PUMP_Z`、`PUMP_A`、`USV_STAT`、`USV_PKT`、`USV_STEP`、`USV_STOT`、`USV_SCNT`、`USV_PERR`、`USV_PMOD`、`USV_BSET`、`USV_REF`、`USV_BASE`、`USV_VLD`。

关键变化是新增的 baseline/valid 字段让 QGC 能区分：

- 有电压但未设 baseline；
- baseline 已设置但当前样本无效；
- 有效样本可用于点采样或走航；
- baseline 参考电压与 baseline 电压的具体数值。

### 8.3 ACK 语义变化

前期风险是 QGC 发分光启动/停止后 ROS trigger 立即 ACK accepted，但泵控节点可能尚未完成 ADS 配置、I2C 映射或串口命令。本周期通过以下方式收敛：

- trigger node 对分光启停调用服务并基于结果返回 accepted/rejected。
- Web 端分光启停和 baseline 也走 `/usv/control_command`，减少 topic 单向发布导致的状态漂移。
- router bridge ACK 发送失败时会重试或挂起，避免 socket 短断导致 ACK 丢失。
